# Remove Abandoned Cars

Removes dummy parked vehicles across the map

### What does this mod do?

- You can delete dummy parked vehicles without owners (from settings)
- You can disable spawning of dummy vehicles
- You can delete not spawned (ghost) vehicles
- Bonus - You can increase from 1x - 7x capacity of all parking spaces in your city (including those on Residential buildings, ect..)
- Bonus - You can remove abandoned trailers in the middle of the road

Mod will clear dummy parked vehicles upon loading and show you cleared amount. It is required to disable dummy traffic spawning in order to preserve clean city.

### Important

Mod incorporate logic from 2 Mimonsi mods:
- [Fix Broken Trailers](https://mods.paradoxplaza.com/mods/136207/Windows)
- [Dummy Traffic Remover](https://mods.paradoxplaza.com/mods/107683/Windows)

Full credits to Mimonsi for those 2 features despite my implementation is different code wise.
(Mimonsi was contacted and gave me permission for this)

This mod require incorporation of logic to disable dummy traffic to be complete solution. Trailers are just bonus.
You can still use those mods if you like them but that will require you to just uncheck things in Settings of this mod.

If you decide to no longer use those mods, please disable them to not have conflicts of logic.
